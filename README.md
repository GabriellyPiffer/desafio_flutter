## Flutter - Aplicativos Mobile

Este projeto foi desenvolvido como parte da Aula 02 - Situações Desafiadoras, com o objetivo de praticar o desenvolvimento de aplicativos utilizando o framework Flutter.

Foram desenvolvidos três aplicativos com recursos de interface, gerenciamento de estado, persistência local e organização utilizando classes de modelo.

## 🎯 Objetivo

Desenvolver pequenos aplicativos de uso local utilizando recursos nativos do Flutter, praticando:

- Criação de interfaces
- Temas claro e escuro
- Ícones e imagens
- Gerenciamento de estado
- Operações assíncronas
- Persistência de dados local
- Conversão de dados
- Classes de modelo
- Listas
- Cards
- Botões
- Gráficos
- Formulários

## 📚 Desafios

### 🚶 Desafio 01 - Caminhadas x Calorias

Aplicativo para registrar caminhadas e calcular o gasto calórico com base no peso do usuário e na distância percorrida.

### 💧 Desafio 02 - Consumo de Água

Aplicativo para registrar o consumo diário de água e acompanhar o histórico dos registros.

### ⛽ Desafio 03 - Abastecimento de Veículos

Aplicativo para registrar abastecimentos e acompanhar informações sobre consumo e gastos com combustível.

## 🛠️ Tecnologias utilizadas

- Flutter
- Dart
- Material Design
- SharedPreferences
- FL Chart
